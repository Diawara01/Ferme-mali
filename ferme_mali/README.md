# Ferme Mali 🇲🇱

Premier prototype Flutter du jeu d'agriculture et d'élevage.

## Lancer le projet

1. Installer Flutter.
2. Ouvrir ce dossier dans Android Studio ou VS Code.
3. Exécuter `flutter pub get`.
4. Exécuter `flutter run`.

## Prochaine étape

Créer l'écran **Ma Ferme** avec :
- parcelles de culture ;
- bovins, moutons, chèvres et volailles ;
- inventaire ;
- récolte ;
- marché ;
- missions ;
- sauvegarde locale puis connexion Laravel.
